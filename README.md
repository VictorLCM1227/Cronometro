# Cronômetro

## Sobre o projeto

Uma aplicação web de cronômetro que permite iniciar, pausar, continuar e zerar a contagem do tempo.

A ideia é criar uma aplicação simples e interativa para praticar o controle de tempo utilizando JavaScript.

## Objetivo

Praticar JavaScript através da criação de uma aplicação que trabalhe com temporização, eventos, manipulação do DOM e controle de estado.

## Funcionamento planejado

1. O cronômetro começa zerado.
2. O usuário clica em **Iniciar**.
3. O JavaScript começa a atualizar o tempo.
4. O usuário pode **pausar** a contagem.
5. Ao clicar em **Continuar**, a contagem continua de onde parou.
6. O usuário pode **zerar** o cronômetro.
7. O botão de **Volta** registra o tempo atual.
8. As voltas ficam armazenadas e são exibidas na página.
